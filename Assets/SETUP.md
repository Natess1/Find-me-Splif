# НАСТРОЙКА НОВЫХ ФИШЕК — Find me Splif

Все скрипты уже написаны. Ниже — что нужно нажать в Unity-редакторе (15–20 минут).

---

## 0. Установка файлов

**Вариант А (проще):** распакуй `find-me-splif-changes.zip` в корень проекта (там, где лежит папка `Assets`) с заменой файлов.

**Вариант Б (через git):**

```
git apply find-me-splif-changes.patch
```

После открытия Unity подожди импорт (создадутся .meta для новых PNG в `Assets/Resources`).

---

## 1. Сцена обучения (TutorialScene)

1. `File → New Scene → Basic (2D)` → сохрани как `Assets/Scenes/Levels/Menu/TutorialScene.unity`
2. Создай пустой объект `Tutorial` → повесь на него скрипт **TutorialPager**
3. Перетащи в сцену префаб `Assets/Prefabs/Scenes/SceneTransition.prefab` (красивый переход)
4. `File → Build Settings → Add Open Scenes` — добавь TutorialScene в билд (ОБЯЗАТЕЛЬНО)
5. Запусти — всё уже работает:
   - 5 страниц: «!» → Ходьба → Дэш → Атака → Хил
   - анимации подтягиваются из `Assets/Resources/Tutorial/Anims/` автоматически
   - стрелки гаснут серым на первой/последней странице
   - «В МЕНЮ» возвращает в главное меню

Настройки в инспекторе TutorialPager: цвета фона/окна/текстов, спрайты стрелок.
Кадры можно заменить вручную: в списке Pages у страницы задай `Frames` (нарезанные спрайты) — они приоритетнее авто-нарезки.

---

## 2. Кнопка «ОБУЧЕНИЕ» в главном меню

1. Открой `MainMenu.unity`
2. Создай пустой объект `TutorialButtonBuilder` (можно прямо на Canvas) → повесь **MainMenuTutorialButton**
3. Готово: кнопка клонирует PlayButton сама (тот же вид), ставится ниже и ведёт в TutorialScene.

Смещение кнопки — `Offset From Play Button` в инспекторе.
Альтернатива вручную: создай кнопку и повесь на неё `MainMenu.LoadTutorialScene()` (метод уже есть).

## 3. Хил-эффект

Спрайт уже лежит в `Assets/Resources/Effects/HealCross.png` — назначать ничего не надо.

На объекте **Player** (в NewPlayScene) появились поля в инспекторе:

- **Heal Effect Duration** — сколько секунд спрайт висит над головой (ТВОЁ «X»)
- **Heal Effect Height** — высота над головой (по умолчанию 1.2)
- **Heal Effect Sprite** — свой спрайт вместо креста (опционально)

Эффект срабатывает при лечении (`Player.Heal()`) — то есть при покупке у торговца.
Следует за игроком, покачивается, плавно появляется и растворяется.

## 4. Система уровней и таймер

1. Открой `NewPlayScene`
2. Создай пустой объект `LevelSystem` → повесь скрипт **LevelSystem**
3. Настройки в инспекторе:
   - **XP Per Level Base** = 10 → уровень N требует N × 10 XP (2-й уровень: 10 XP, 3-й: 20 суммарно и т.д.)
   - **Sword Bonus Per Level** = 1 → меч: +1 урона за уровень

Как это работает:

- У каждого `EnemySO` (SceletonSO и т.д. в `Assets/ScriptableObjects`) появилось поле **XP Reward** (по умолчанию 5). XP даётся при убийстве.
- У **Sword** (в инспекторе оружия) появились `Base Damage` и `Scale With Level`.
- Уровень живёт один забег: при загрузке NewPlayScene сбрасывается.
- При смерти сохраняются: `last_run_time`, `last_run_level` + рекорды `best_time`, `best_level`.

## 5. HUD: таймер и уровень

1. В Canvas (NewPlayScene) создай два TMP-текста:
   - таймер (например, вверху по центру)
   - уровень (рядом с деньгами/сердцем)
2. На объекте **GameInput** назначь новые поля в инспекторе: **Timer Text** и **Level Text**

Таймер идёт с момента загрузки сцены, формат `мм:сс`. Если поля не назначены — HUD просто не покажет их, ошибок не будет.

---

## 6. Волны врагов

1. В NewPlayScene создай пустой объект `WaveSpawner` → повесь скрипт **WaveSpawner**
2. В **Enemy Prefabs** назначь: `Sceleton.prefab` и `Goblin.prefab` (Assets/Prefabs/Enemies/Sceleton)
3. Настройки волн в инспекторе:
   - First Wave Delay = 5 сек, Wave Interval = 20 сек (каждая волна на 5% быстрее, минимум 8 сек)
   - Base Enemy Count = 3, +1 враг за каждую волну, максимум 25 живых
   - Спавн вокруг игрока на радиусе 8–14, только на валидных точках NavMesh

**ВАЖНО:** чтобы враги из волн шли к игроку, в их префабах (EnemyAI) должен быть включён чекбокс **Is Chaising Enemy**. Спавненные волной враги первые 6 секунд принудительно преследуют игрока (`ForceChase`), потом живут как обычно.

## 7. Экран смерти: итоги и рекорды

1. Открой `DeathScene`
2. На объекте Canvas создай новый TMP-текст (например «RunStats») в свободном месте
3. Повесь на Canvas скрипт **DeathScreenStats** → назначь в него этот текст

Выводит:

```
Продержался: 03:25
Достигнут уровень: 7

Рекорд: 05:10 / Ур. 9
```

Если поле Text пустое — скрипт попробует найти объект `DeathText` (но тогда заменит «Вы умерли» — лучше создать отдельный текст).
Рекорды включаются/выключаются галкой **Show Records**.
